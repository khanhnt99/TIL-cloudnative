# Production environment
## 1. Production considerations
- **Availability**: Creating a highly available cluster means considering
  + Separating the control plane from the worker nodes.
  + Replicating the control plane components on multiple nodes.
  + Load balancing traffic to the cluster’s API server.
  + Having enough worker nodes available, or able to quickly become available, as changing workloads warrant it.
- **Scale**
- **Security and access management:** You can use role-based access control (RBAC) and other security mechanisms to make sure that users and workloads can get access to the resources they need, while keeping workloads, and the cluster itself, secure. You can set limits on the resources that users and workloads can access by managing policies and container resources.
